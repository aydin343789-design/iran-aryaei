# ایران آریایی 5.0

مجموعه ابزارهای کاربردی اندروید با رابط AI Agent و پردازش محلی.

## ویژگی‌ها

- 34 ابزار آفلاین
- دستیار محلی فارسی با Intent Engine
- نرمال‌سازی فارسی و امتیازدهی ترکیبی
- ذخیره خروجی در `Download/Iran Aryaei`
- اشتراک‌گذاری با Android Share Sheet
- تاریخچه عملیات
- Splash Screen
- حالت تاریک
- QR ساز و QR خوان با ML Kit و ZXing
- فشرده‌سازی تصویر، صوت و ویدئو
- تبدیل صوت به MP3
- عکس به PDF و PDF به عکس
- ادغام PDF
- مقایسه متن خط‌به‌خط
- دیتابیس آفلاین شهرها
- فرهنگ لغت آفلاین فارسی/انگلیسی

## ساخت با GitHub

پروژه برای GitHub Actions آماده است. کافی است محتویات Repository در ریشه قرار بگیرد و Workflow `Build Iran Aryaei APK` اجرا شود.

## داده‌های آفلاین

داده‌های شهرها در `www/cities.json` و فرهنگ لغت در `www/dictionary.json` قرار دارند. این فایل‌ها بدون API و بدون اینترنت در برنامه خوانده می‌شوند.

## Android

پروژه Native کامل در پوشه `android` قرار دارد و پل Kotlin در `NativeToolsPlugin.kt` پیاده‌سازی شده است.
