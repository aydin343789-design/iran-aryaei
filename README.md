## داده‌های آفلاین

- بانک فاصله شهرها: 166 شهر مهم/اداری ایران با نام فارسی/انگلیسی، alias و مختصات.
- دیکشنری: 980 مدخل یکتا فارسی↔انگلیسی با جستجوی نرمال‌شده.
- تمام داده‌ها داخل APK و بدون API/سرور استفاده می‌شوند.

## ذخیره خروجی

خروجی‌های Native و خروجی ابزارهای JS از طریق Bridge در Android 10+ به `Downloads/Iran Aryaei` می‌روند. اشتراک‌گذاری فایل نیز با FileProvider انجام می‌شود.

## نکته سازگاری

- HEIC encoding به Android 10+ و encoder HEIC دستگاه نیاز دارد.
- MP3 encoding در Android به‌صورت استاندارد روی همه دستگاه‌ها تضمین نمی‌شود؛ MP3 ورودی بدون افت کپی می‌شود و تبدیل غیر-MP3 فقط روی دستگاه دارای encoder مناسب انجام می‌شود.
- حذف پس‌زمینه فعلاً برای پس‌زمینه‌های ساده/یکنواخت طراحی شده و مدل AI segmentation نیست.
- فشرده‌سازی ویدئو از MediaCodec استفاده می‌کند و سازگاری encoder/decoder وابسته به chipset دستگاه است.
