# عکس‌های لوگوی اصلی شما را اینجا بگذارید

دو فایل زیر را (با همین نام‌ها) در این پوشه قرار دهید:

| فایل | کاربرد |
| --- | --- |
| `square.png` | نسخهٔ مربعی — آیکون اپ (وب و اندروید) |
| `round.png` | نسخهٔ دایروی — صفحهٔ ورود (Splash) و سرعنوان |

پس‌بندی `.jpg` هم می‌شود. سپس یک دستور:

```bash
node scripts/use-my-logos.mjs
```

همهٔ اندازه‌های آیکون (وب + لاندر اندروید در همهٔ تراکم‌ها) به‌صورت خودکار از همین عکس‌های اصلی ساخته می‌شوند.
